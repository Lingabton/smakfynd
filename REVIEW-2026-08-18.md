# Smakfynd Super Review — 2026-08-18

Comprehensive audit from security, code quality, UX/customer, SEO, and accessibility perspectives.

## Critical & High Issues (Action Required)

### CRITICAL

| # | Area | Issue |
|---|------|-------|
| C1 | UX | **No store availability.** Users can't see if a wine is available at their local Systembolaget. This is the #1 expected feature for a wine recommendation tool. |
| C2 | Code | **build_app.py silently skips missing files.** Missing source files produce a broken build with exit code 0. Should `sys.exit(1)` on any missing file. |
| C3 | Code | **wines.json written before QA cleaning in build_slim.py.** The output may contain incomplete/dirty records that the QA step removes from memory but NOT from the written file. |

### HIGH — Security

| # | Issue | Fix |
|---|-------|-----|
| S1 | **No CSP meta tag at all.** CLAUDE.md claims one exists, but it doesn't. Site has zero Content-Security-Policy protection. | Add CSP meta tag to deploy_html.py template |
| S2 | **Analytics GET endpoints completely unauthenticated.** `/stats`, `/top-searches`, `/ai-queries`, `/sessions`, `/trend` expose business metrics to anyone. | Add `X-Admin-Key` check |
| S3 | **Report worker `/send` publicly accessible.** Anyone can spam-trigger weekly report emails. | Add admin key auth |
| S4 | **`POST /prices` has no authentication.** Attackers can corrupt price history data. | Add admin key auth |

### HIGH — Code Quality

| # | Issue | Fix |
|---|-------|-----|
| Q1 | **App.jsx is a 773-line monolith.** 25+ useState, 7+ useEffect, all inline. Causes unnecessary re-renders. | Refactor into smaller components |
| Q2 | **wines.json is 2.4 MB.** Slow on mobile. Optional fields (critics, taste profiles) could be lazy-loaded. | Strip non-essential fields or paginate |
| Q3 | **No atomic writes in scoring pipeline.** If score_wines_v2.py crashes mid-write, downstream reads corrupt JSON. | Write to temp file, then rename |
| Q4 | **fetch_systembolaget.py breaks pagination silently.** One API error → zero wines for that category, script continues with partial data. No count validation. | Add minimum wine count check |
| Q5 | **Minimal test coverage.** Core scoring algorithm, price computation, Bayesian shrinkage — all untested. Only 3 smoke tests exist. | Add scoring unit tests |

### HIGH — UX

| # | Issue | Fix |
|---|-------|-----|
| U1 | **Main search has no fuzzy matching.** "Chardonay" (typo) → zero results. StoreMode has Levenshtein but main app doesn't. | Port fuzzy search from StoreMode |
| U2 | **50-wine cap says "logga in för att se hela listan" — but login doesn't unlock more.** False promise erodes trust. | Remove misleading text or implement |
| U3 | **No grape/varietal quick filter.** Non-experts think "I want Malbec" — must dig through 2 clicks of hidden filters. | Add grape filter to primary filters |
| U4 | **Minimal responsive CSS.** Only one `@media` query in entire app. Font sizes, gaps don't adapt between 320px–680px. | Add mobile breakpoints |

### HIGH — Accessibility

| # | Issue | Fix |
|---|-------|-----|
| A1 | **Color contrast fails WCAG AA.** `#9e9588` on `#f5f1ea` = ~2.5:1 ratio (needs 4.5:1). Affects timestamps, metadata, footer. | Darken to at least `#756b5e` |
| A2 | **FAQ accordion is keyboard-inaccessible.** `<div>` with `onClick`, no `role="button"`, no `tabIndex`, no keyhandler. | Add proper ARIA + keyboard support |
| A3 | **No skip-to-content link.** Screen reader users must tab through header, age gate, nav before content. | Add skip link |

## Medium Issues

| # | Issue |

## What's Working Well

**Security:** CORS locked to smakfynd.se, SQL injection fully mitigated (parameterized queries), HTTPS redirect, proper .gitignore, Supabase PKCE auth flow, worker secrets in env vars.

**Architecture:** Clean no-bundler approach (React via CDN + Babel transpile), GitHub Pages deploy, CF Workers for backend, D1 for analytics. Simple and cheap to run.

**SEO:** Strong structured data (ItemList + BreadcrumbList + FAQPage + WebPage), 88 landing pages, year in titles, Norwegian targeting, ChatGPT referral capture (8% of traffic).

**UX:** Clear value proposition ("5000+ viner rankade"), trust signals (named founder, independence statement, methodology transparency), rich wine cards with score breakdown, AI food matcher, deep linking via hash routing.

**Data:** Sound scoring algorithm (crowd + expert + price value), daily automated updates, Vivino + 6 expert sources, price history tracking.
